# 提取自一份 30 集古装言情短剧剧本改写 Agent 任务日志

## 问题场景概述：

- 30 集，单集 120 至 150 秒规格；先由 Agent 流水线生成初稿，再由人工做一轮文字审校。

- 人工审校得出并界定了四类待修订问题：内部矛盾 / 表达晦涩 / 史实与名物校准 / 语体贴合。

- 人工修订条目 117 条，分布为：内部矛盾 41、表达晦涩 52、史实与名物错置 16、现代词与 AI 腔 4；另有敏感词表命中 5 处。


## 典型问题：如何处理文本内部固有矛盾

### 形态分布

- 人物事实与附表冲突：年龄、称谓、亲属关系、生死状态。

- 位置与状态不接续：上一拍坐着下一拍站着；人物在甲处而动作按乙处写。

- 时序倒流与节令错置：同一场的光照与时段标错；季节标记与前后集矛盾。

- 道具漂移：名称、材质、携带方式前后不一致，或在别集已改定而此处未跟进。

- 场名与场内容不符：同一条场名被复制到不相干的几场。

- 参照物不一致：同一份文书在两处叫法不同；引用的原句实际出自另一处。

### 两类不可混同的矛盾

- **A 明确错误**：可用脚本检出，属事实性矛盾。

- **B 疑似错误、实为伏笔**：两处表述方向相反，但后文有呼应，属有意安排。

判定难点在于，B 类与 A 类在最终稿上的形态完全相同，都表现为“不一致”。主动将 B 类改写，从产物上看不出问题；只有拿到“矛盾清单”（矛盾双方、判别依据、处置动作）才能判定。

### 如何测评

- 脚本层：需要自原文统计出附表，严格核对数字、称谓、道具词、场名关键词。

- LLM Judge 层：是否准确识别出矛盾、判别依据是否按层级顺序、处置是否遵循最小必要原则。
